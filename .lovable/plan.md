# Daily Report Sharing — Export PDF & PNG

Add two one-click export buttons to the dashboard that produce a polished, shareable daily report containing KPIs, the full Gantt chart, a date/shift header, a per-lay summary table, and company branding.

## What gets added

**Toolbar (top-right of dashboard):**
- `Export PDF` button — downloads a landscape A4 PDF
- `Export PNG` button — downloads a high-res image (good for WhatsApp/Teams)

## Report layout (single page, landscape)

```text
┌────────────────────────────────────────────────────────────┐
│ [LOGO]   CW Cutting Department — Daily Schedule            │
│          Date: 01 Jun 2026   Shift: Day   Generated: 18:30 │
├────────────────────────────────────────────────────────────┤
│ [30% Cutter Util] [13.6 hr Idle] [10 Lays] [4 Issues]      │
├────────────────────────────────────────────────────────────┤
│              FULL GANTT CHART (spreaders + cutters)        │
│              Legend: Spreading / Cutting / Idle / Break    │
├────────────────────────────────────────────────────────────┤
│ Lay No │ Plies │ Spread Start │ Spread Dur │ Cut Dur │ ... │
│  199-28│  120  │   07:00      │   45m      │   18m   │ OK  │
│  ...                                                       │
├────────────────────────────────────────────────────────────┤

```

## How it works (technical)

- Use `html2canvas` to snapshot the report DOM at 2× scale → PNG
- Use `jspdf` to embed that canvas into a landscape A4 PDF
- Build a hidden `#reportContainer` div that renders: branded header + KPI strip + Gantt + summary table, styled for print (white bg, no scrollbars, full timeline visible)
- Filename: `CW-Cutting-Schedule_2026-06-01.pdf` / `.png`
- All client-side — no backend, instant download
