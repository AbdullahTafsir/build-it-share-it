Connect to Supabase
This is a one-time setup. Your credentials are saved locally on this server.
After this, all data syncs to Supabase automatically — no action needed.
Step 1: Go to supabase.com → open (or create) your project
Step 2: Open the SQL Editor and run the schema below (click "Show SQL schema")
Step 3: Go to Settings → API → copy Project URL and anon public key
Step 4: Paste them below and click Connect
